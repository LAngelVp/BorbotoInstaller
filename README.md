# 🍽️ Borboto POS & KDS

## Sistema integral para la operación de tu restaurante

**Borboto POS & KDS** es una solución diseñada para ayudarte a administrar las operaciones diarias de tu restaurante desde un solo sistema.

Puedes gestionar pedidos, mesas, cocina, caja, ventas, clientes, promociones, delivery y mucho más.

El sistema conecta las diferentes áreas del restaurante para que la información fluya de manera rápida y organizada.

---

# 🌟 ¿Qué puedes hacer con Borboto?

Borboto integra las principales operaciones de un restaurante:

* 🛒 Punto de venta.
* 🪑 Control de mesas.
* 👨‍🍳 Pantalla de cocina.
* 🧾 Comandas.
* 💰 Caja.
* 🧾 Cortes de caja.
* 🖨️ Impresión de tickets.
* 🧾 Facturación.
* 🚴 Pedidos a domicilio.
* 🛍️ Pedidos de mostrador.
* 👥 Clientes.
* ⭐ Programa de fidelidad.
* 🎟️ Cupones.
* 🎁 Promociones.
* 🏷️ Descuentos.
* 🍔 Productos.
* 📊 Dashboard de ventas.
* 👨‍💼 Control de usuarios y empleados.

# 🛒 Punto de venta

El punto de venta permite registrar las operaciones realizadas con los clientes.

Desde el POS puedes:

* Seleccionar productos.
* Crear pedidos.
* Asociar clientes.
* Aplicar promociones.
* Aplicar descuentos.
* Utilizar cupones.
* Cobrar.
* Imprimir tickets.

El objetivo es que el proceso de venta sea rápido y sencillo.

---

# 🪑 Control de mesas

El sistema permite visualizar y administrar las mesas del restaurante.

Puedes conocer cuáles están:

* Libres.
* Ocupadas.
* Reservadas.
* Pendientes de limpieza.

Al seleccionar una mesa puedes consultar y administrar su cuenta.

---

# 🔄 Cambiar una cuenta de mesa

Si un cliente cambia de mesa, puedes trasladar su cuenta a otra mesa sin tener que volver a capturar todo el pedido.

Ejemplo:

**Mesa 4 → Mesa 8**

La cuenta y los productos asociados permanecen relacionados con la operación.

---

# 🧾 Comandas

Cuando un pedido es registrado, la información puede enviarse a cocina.

Esto evita tener que comunicar manualmente cada pedido.

El flujo habitual es:

```text
Mesero
  ↓
Toma pedido
  ↓
Registra pedido
  ↓
Cocina recibe comanda
  ↓
Cocina prepara
  ↓
Pedido listo
  ↓
Mesero entrega
```

---

# 👨‍🍳 Pantalla de cocina

La pantalla de cocina permite que el personal vea los pedidos pendientes de preparación.

Las comandas pueden avanzar por diferentes estados:

**Pendiente → En preparación → Listo → Entregado**

Esto permite que cocina tenga una visión clara de los pedidos que debe preparar.

---

# ⏱️ Control de tiempos

El sistema puede mostrar información relacionada con el tiempo que lleva cada pedido en preparación.

Esto ayuda al personal a identificar pedidos que llevan demasiado tiempo pendientes y priorizar su atención.

---

# 💰 Caja

El módulo de caja permite controlar las operaciones económicas realizadas durante el turno.

Puedes gestionar:

* Apertura de caja.
* Operaciones.
* Cobros.
* Movimientos.
* Cierre.
* Corte de caja.

---

# 📊 Cortes de caja

Al finalizar un turno o periodo de trabajo puedes realizar un corte de caja.

El corte permite revisar las operaciones realizadas durante ese periodo y facilitar el control administrativo.

Se recomienda realizar los cortes de acuerdo con las políticas de operación de cada negocio.

---

# 🖨️ Tickets

Borboto permite imprimir tickets de las operaciones realizadas.

Los tickets pueden utilizarse como comprobantes para los clientes y como referencia de la operación.

Antes de imprimir verifica que:

* La impresora esté encendida.
* Tenga papel.
* Esté conectada.
* Se encuentre disponible.

---

# 🖨️ Impresión

El sistema permite trabajar con impresoras configuradas para las necesidades del restaurante.

Si una impresora no está disponible, comprueba primero que esté encendida y correctamente conectada.

---

# 🧾 Facturación

Borboto puede incluir funciones de facturación para las operaciones que requieran comprobantes fiscales.

La disponibilidad y funcionamiento de estas opciones dependen de la configuración del establecimiento y de los servicios de facturación utilizados.

---

# 🚴 Pedidos a domicilio

El módulo de delivery permite administrar los pedidos realizados para entrega a domicilio.

Puedes controlar el proceso desde la recepción del pedido hasta su entrega.

Flujo habitual:

```text
Pedido recibido
      ↓
Preparación
      ↓
Pedido listo
      ↓
Asignación de repartidor
      ↓
En camino
      ↓
Entregado
```

---

# 🛍️ Pedidos en mostrador

Los clientes que realizan pedidos directamente en el establecimiento pueden gestionarse mediante el flujo de mostrador.

Esto permite diferenciar este tipo de pedidos de las cuentas asociadas a mesas.

---

# 👥 Clientes

Borboto permite crear y administrar una base de clientes.

Puedes guardar información que facilite:

* Identificar al cliente.
* Consultar compras anteriores.
* Aplicar beneficios.
* Gestionar fidelidad.
* Utilizar promociones.

---

# ⭐ Programa de fidelidad

El sistema puede recompensar a los clientes mediante un programa de puntos.

El funcionamiento general es:

```text
Cliente realiza compra
        ↓
Obtiene puntos
        ↓
Acumula puntos
        ↓
Obtiene beneficio
        ↓
Canjea puntos
```

Las reglas de acumulación y canje dependen de la configuración del negocio.

---

# 🎟️ Cupones

Los cupones permiten ofrecer beneficios especiales a los clientes.

Pueden utilizarse para campañas promocionales y ofertas determinadas.

Antes de finalizar una venta, verifica que el cupón aplicado corresponda a las condiciones establecidas.

---

# 🎁 Promociones

Las promociones permiten ofrecer ofertas especiales.

Pueden utilizarse para:

* Incentivar ventas.
* Promover productos.
* Crear campañas.
* Ofrecer beneficios a clientes.

---

# 🏷️ Descuentos

Los descuentos permiten modificar el importe de una venta de acuerdo con las reglas establecidas.

Dependiendo de los permisos del usuario, algunas operaciones pueden requerir autorización.

---

# 🍔 Productos

El catálogo de productos contiene los artículos que pueden venderse desde el sistema.

Cada producto puede tener información como:

* Nombre.
* Precio.
* Categoría.
* Disponibilidad.
* Información adicional.

Mantener actualizado el catálogo ayuda a evitar errores durante las ventas.

Las gráficas ayudan a responder preguntas como:

* ¿Cuánto se está vendiendo?
* ¿Qué productos tienen mayor movimiento?
* ¿Cuáles son los horarios con mayor actividad?
* ¿Cómo está funcionando el negocio?

La información disponible depende de los datos registrados en el sistema.

# 🔄 Información en tiempo real

Una de las principales ventajas de Borboto es que diferentes áreas pueden trabajar con la información actualizada.

Por ejemplo:

```text
Mesero registra pedido
        ↓
Cocina recibe pedido
        ↓
Cocina cambia estado
        ↓
Mesero puede conocer el estado
```

Esto ayuda a reducir errores de comunicación y mejora la coordinación entre las áreas.

---

# 📋 Ejemplo de operación completa

Una operación típica puede seguir este proceso:

### 1. Cliente llega

El mesero asigna una mesa.

### 2. Se toma el pedido

Los productos se agregan desde el punto de venta.

### 3. Cocina recibe la comanda

La orden aparece en la pantalla de cocina.

### 4. Cocina prepara

El personal cambia el estado del pedido conforme avanza.

### 5. Se entrega

El pedido listo se entrega al cliente.

### 6. Se realiza el cobro

El cajero procesa el pago.

### 7. Se imprime el ticket

El cliente recibe su comprobante.

### 8. Se registra la venta

La información queda disponible para las consultas y estadísticas.

# ⚠️ Problemas frecuentes

## No puedo entrar

Comprueba que estés utilizando correctamente tus datos de acceso.

Si continúas sin poder entrar, consulta al administrador.

---

## No aparece una mesa

Comprueba que la mesa esté correctamente configurada y que tu usuario tenga permiso para verla.

---

## No aparece una comanda en cocina

Comprueba que el pedido haya sido enviado correctamente.

Si continúa sin aparecer, solicita asistencia.

---

## No imprime el ticket

Comprueba:

* Impresora encendida.
* Papel disponible.
* Conexión correcta.
* Impresora seleccionada.

---

## No puedo aplicar un descuento

Es posible que tu usuario no tenga permiso para realizar esa operación.

Consulta con el administrador.

---

## No puedo utilizar una promoción o cupón

Comprueba que:

* Esté vigente.
* Corresponda al producto o pedido.
* Cumpla las condiciones establecidas.

Si continúa el problema, solicita asistencia.

Para utilizar Borboto correctamente:

* Utiliza tu propia cuenta.
* No compartas tu contraseña.
* Revisa los pedidos antes de confirmarlos.
* Verifica descuentos y promociones.

* Realiza los cortes de caja correctamente.
* Mantén actualizada la información de los productos.
